# Как добавить статью в журнал

Журнал — это папка с markdown-файлами. Сайт собирает из них список `/journal` и страницу `/journal/<slug>`. Если в папке нет файлов статей, список открывается и показывает, что статей нет, и страница не индексируется. Ссылка «Журнал» в меню есть и в этом случае.

Не пишите статью в `pages/` — эти HTML-файлы перезаписывает сборка.

## 1. Файл статьи

Создайте `content/journal/<slug>.md`.

Slug — имя файла без `.md`: латиница в нижнем регистре, цифры и дефис. Например, `svet-v-gostinoi.md` → адрес `/journal/svet-v-gostinoi`.

Нельзя называть файл `page.md` — это слово занято пагинацией (`/journal/page/2`).

## 2. Шапка

```md
---
title: Свет в гостиной — Studio19.03
description: Как заложить свет в гостиной до начала ремонта: сценарии, высота и то, что лучше решить на проекте.
h1: Свет в гостиной решают до ремонта
excerpt: Короткий абзац для карточки в списке журнала. Одна-две фразы, без разметки.
date: 2026-11-01
cover: /images/journal/svet-v-gostinoi/cover.jpg
coverAlt: Гостиная с тёплым светом, вид от окна
---
```

| Поле | Куда попадает |
|---|---|
| `title` | `<title>`, Open Graph. Можно длиннее H1 и с именем студии. |
| `description` | Meta description и Open Graph. Ориентир — 150–160 знаков, не длиннее 320. |
| `h1` | Заголовок на странице и на карточке. |
| `excerpt` | Текст карточки. Обычный текст, без ссылок и звёздочек. До 400 знаков. |
| `date` | Дата публикации, `ГГГГ-ММ-ДД`. В списке новые сверху. |
| `cover` | Обложка: путь от корня сайта (`/images/...`) или полный `https://`. |
| `coverAlt` | Подпись к обложке для скринридера и Open Graph. |
| `updated` | Необязательно. Дата правки, если статья менялась. Не раньше `date`. |
| `draft` | Необязательно. `draft: true` — файл не попадает на сайт. |
| `slug` | Необязательно. Если указан, должен совпасть с именем файла. |

Картинка показывается целиком: на всю ширину колонки, с естественной пропорцией, без обрезки по бокам. Класть можно и вертикальные, и широкие кадры.

Файлы обложки и фото в тексте положите в `images/journal/<slug>/`. Сборка проверяет, что локальный файл существует.

## 3. Текст

После второй строки `---` — тело. Пустая строка разделяет абзацы.

```md
Первый абзац. Внутри можно сослаться на [портфолио](/portfolio) или на другую статью: [свет](/journal/svet-v-gostinoi).

## Подзаголовок

Абзац раздела. **Жирное** и *курсив* — звёздочками.

### Подзаголовок меньше

- Пункт списка
- Второй пункт

![Подпись под фото](/images/journal/svet-v-gostinoi/okno.jpg)

:::faq
На какой высоте вешать бра?

Обычно 140–160 см от пола до центра. Точную отметку лучше снять на объекте.

Можно ли оставить один верхний свет?

Можно, но сценарий «только люстра» быстро устаёт. Нижний свет добавляют ещё на проекте.
:::
```

Что поддерживается:

- абзацы;
- `##` и `###`;
- ссылки `[текст](/portfolio)` — внутренние с `/`, а также `https://`, `mailto:`, `tel:`;
- картинка отдельной строкой `![подпись](/images/...)` — подпись видна под фото;
- список `- пункт`;
- блок `:::faq` … `:::`.

В FAQ вопрос и ответ чередуются и разделяются пустой строкой. Заголовок «Вопросы и ответы» подставляется сам. Из этого блока собирается FAQ в разметке Schema.org. Если вопросов нет, блок просто не пишите.

Не вкладывайте ссылку внутрь жирного и не ставьте скобки в адрес ссылки.

## 4. Сборка и проверка

```bash
node scripts/build.js
npm run dev
```

- http://localhost:8080/journal — список, 12 карточек на страницу, дальше `/journal/page/2`
- http://localhost:8080/journal/<slug> — статья

Пуш в `main` собирает сайт в GitHub Actions и выкладывает его на Onreza. Локально то же самое делает `npm run build`, затем `nrz deploy --prod`.

Черновик (`draft: true`) можно коммитить: на сайте его не будет, пока строку не уберёте и не задеплоите снова.
